# ai-collective-loom

A planned persistent collaboration and knowledge environment for human–AI collectives.

The [product specification](docs/ai-collective-loom-product-specification.md)
(version 0.9) defines the baseline for architecture design and human/agent
interaction prototypes. The repository has no application implementation yet.

Bootstrapped with [Lore Coding](AGENTS.md).

To enable commit hooks in a clone, run `node .githooks/install-lore-coding-hooks.mjs`.
